# Get help / Yardım

## Using Depo Dolu

- [Open the web app](https://ozkurtomer.github.io/depo-dolu/).
- [Read the API reference](docs/API.md) for field names, timestamps and source limitations.
- [Follow Telegram alerts](https://t.me/depodolu) if you want updates without a native app.

## Report a problem

Use the [bug report form](https://github.com/ozkurtomer/depo-dolu/issues/new?template=bug_report.yml). Include the province, fuel, device/browser, expected behavior and reproduction steps. For a price discrepancy, include when you checked it and the public source. The dataset contains Petrol Ofisi province list prices; pump prices and other distributors may differ.

Bir sorun bildirirken ilini, yakıtını, cihaz/tarayıcını, beklediğin sonucu ve tekrar adımlarını yaz. Token, servis hesabı anahtarı veya kişisel bilgi ekleme.

Feature ideas belong in the [feature form](https://github.com/ozkurtomer/depo-dolu/issues/new?template=feature_request.yml). Discuss larger work before implementing it. Small contributions are listed in the [roadmap](docs/ROADMAP.md).

For security reports, follow [SECURITY.md](SECURITY.md). This community project does not promise response times or continuous service availability.
